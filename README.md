## 🌟 Overview

**Urdu PhotoCraft Studio 2.0** brings Photoshop-grade graphic design workflows to Urdu speakers, poets, content creators, and graphic designers worldwide. 

Designing authentic Urdu content in generic photo editors is notoriously difficult: Urdu script (Nastaliq) connects letters with intricate baseline shifts, requiring specialized rendering and text effects. Traditional photo editing tools lack native Urdu phonetic keyboards, Islamic calligraphy seals, and curated poetry libraries.

**Urdu PhotoCraft** solves this entirely in the browser with zero installation required, offering high-DPI rendering up to **4K resolution**, interactive multi-layer manipulation, and bi-directional bilingual support (**English & Urdu**).

## ✨ Key Features

### 🖋️ Authentic Urdu Typography Engine
- **Curated Font Library**: Handpicked Urdu and Arabic typefaces:
  - `Noto Nastaliq Urdu` (Traditional cascading Nastaliq)
  - `Gulzar` (Modern display Nastaliq)
  - `Amiri` (Classical Naskh)
  - `Aref Ruqaa` (Expressive Arabic script)
  - `Noto Sans Arabic` (Clean modern geometric)
- **Advanced Text Effects**:
  - **Multi-Color Stroke Outlines**: High-contrast outlines with adjustable width for legible text over complex backgrounds.
  - **Dynamic Drop Shadows**: Smooth blur radius, horizontal & vertical offsets, and opacity control.
  - **Dual-Tone Gradient Fills**: Presets including *Royal Gold*, *Emerald Jade*, *Sunset Flame*, and *Neon Cyan*.
  - **Background Highlight Ribbons**: Subtitle-style background ribbons with customizable opacity and corner radius.
- **Interactive Canvas Controls**:
  - Direct on-canvas dragging, 8-point interactive resizing handles, rotation, and selection outlines.

### 🖼️ Canvas & Background Engine
- **Preset Social Aspect Ratios**:
  | Preset | Aspect Ratio | Dimensions (1x Base) | Ideal For |
  | :--- | :---: | :---: | :--- |
  | **Square Post** | `1:1` | 1080 × 1080 | Instagram Posts, WhatsApp DP |
  | **Story / Reel** | `9:16` | 1080 × 1920 | Instagram Stories, TikTok, YouTube Shorts |
  | **Landscape / Thumbnail** | `16:9` | 1920 × 1080 | YouTube Thumbnails, Facebook Banners |
  | **Poetry Card** | `4:3` | 1200 × 900 | Classic Urdu Poetry Cards |
  | **Portrait Card** | `3:4` | 900 × 1200 | Pinterest Pins, Book Covers |
- **Rich Background Options**:
  - 20+ curated gradient palettes (*Royal Obsidian*, *Imperial Brass*, *Midnight Sapphire*, *Sunset Crimson*).
  - Solid background colors with real-time color pickers.
  - Custom photo uploader (drag & drop or file browse).
- **Photo Processing Sliders**:
  - **Darkness Overlay**: Darkens background photos to ensure Urdu text pops with maximum contrast.
  - **Gaussian Blur**: Soft focus backgrounds for elegant quote cards.
  - **Brightness & Contrast**: Precision exposure adjustment.
  - **Vignette**: Vignette framing effect.

---

### ⌨️ Virtual Urdu Phonetic Keyboard
- Built-in on-screen Urdu virtual keyboard mapping English QWERTY phonetics to Urdu letters (`A` -> `ا`, `B` -> `ب`, `P` -> `پ`, etc.).
- Complete diacritics support (Zabar, Zer, Pesh, Tashdeed, Tanween, Hamza).
- Perfect for creators using standard English keyboards without Urdu OS input packs installed.

---

### 🌐 Bilingual User Interface (English & Urdu)
- Seamless bi-directional internationalization (`i18n`).
- Toggle between **English (LTR)** and **Urdu (RTL)** with one click.
- All tooltips, menus, layer titles, and modal dialogs are localized.

---

### 📑 Layer Inspector System
- Layer stack with visual ordering (top to bottom).
- **Lock / Unlock**: Prevent accidental modifications to completed layers.
- **Hide / Show**: Quickly preview designs with or without specific elements.
- **Reordering**: Move layers up or down in the z-index hierarchy.
- **Duplicate & Delete**: Quick clone and clean actions.
- **Layer Opacity**: 0% to 100% fine-grained transparency slider.

---

### 💾 4K High-Resolution Multi-Format Exporter
- **Export Formats**: `PNG` (lossless with transparency support), `JPEG` (optimized compression), `WebP` (modern web standard).
- **Resolution Multipliers**:
  - **1x Standard** (Web & Mobile preview)
  - **2x Ultra HD** (Crisp Retina & Social Media 4K)
  - **3x Print Quality** (300 DPI high-resolution poster print)
- **1-Click Copy to Clipboard**: Copies the rendered canvas directly to the system clipboard for immediate pasting into WhatsApp, Telegram, or Twitter.

## 🎨 AppTheme System

Urdu PhotoCraft features a modular CSS design token architecture under `apptheme/`:

| Theme Name | Style Code | Description |
| :--- | :--- | :--- |
| **Dark Studio (Obsidian Pro)** | `theme-studio` | Deep slate obsidian `#0b0f19` with electric cyan accents and glassmorphism. (Default) |
| **Shaan-e-Urdu (Royal Gold)** | `theme-gold` | Warm dark espresso `#120e0a` with polished gold `#f5c97a` and brass accents. |
| **Quranic Emerald (Jade)** | `theme-emerald` | Forest obsidian `#07130e` with glowing emerald `#10b981` accents. |

Themes persist across browser sessions using `localStorage`.

## 📂 Architecture & Folder Structure

Urdu PhotoCraft is architected following **Feature-First & Clean Separation of Concerns**:

```
urdu-photocraft/
├── index.html                   # Studio workbench DOM layout & toolbar structure
├── main.js                      # Application coordinator & event wiring
├── package.json                 # Project metadata & Vite scripts
├── package-lock.json            # Deterministic dependency lockfile
├── README.md                    # Project documentation
│
├── apptheme/                    # 🎨 AppTheme Design System
│   ├── colors.css               # Color tokens & theme skins (Studio, Gold, Emerald)
│   ├── typography.css           # Urdu Nastaliq & Latin typography scales
│   ├── components.css           # Buttons, range sliders, pickers, inputs, modals
│   ├── workbench.css            # Studio layout (Top bar, Left toolbar, Viewport, Inspector)
│   ├── theme.css                # Master stylesheet aggregator
│   └── theme.js                 # Theme switcher & persistence logic
│
├── core/                        # ⚙️ Core Infrastructure
│   ├── event_bus.js             # Decoupled Pub/Sub messaging bus
│   ├── state.js                 # Reactive application state store
│   ├── history_manager.js       # Undo / Redo snapshot stack
│   └── i18n.js                  # Bi-directional (EN/UR) localization engine
│
└── features/                    # 🚀 Feature-First Modules
    ├── canvas/                  # Canvas rendering & viewport engine
    │   ├── canvas_presets.js    # Aspect ratio definitions & dimensions
    │   ├── canvas_renderer.js   # High-DPI canvas drawing & layer compositor
    │   └── canvas_view.js       # Viewport zoom, pan, hit-testing & interactive resize handles
    ├── text_editor/             # Urdu Typography Engine
    │   ├── text_layer.js        # Text layer model & factory
    │   ├── text_styling.js      # Font families, sizes, alignments
    │   ├── text_effects.js      # Stroke outlines, drop shadows, gradient fills
    │   └── urdu_keyboard.js     # Virtual phonetic on-screen Urdu keyboard
    ├── poetry_library/          # Urdu Poetry & Presets Library
    │   ├── poetry_data.js       # Curated Iqbal, Ghalib, Faiz & Islamic poetry database
    │   └── poetry_modal.js      # Searchable poetry modal with 1-click canvas insertion
    ├── background_manager/      # Background & Photo Filter Engine
    │   ├── bg_colors.js         # Curated gradients & solid palettes
    │   ├── bg_uploader.js       # File loader & image dimensions reader
    │   └── bg_filters.js        # Darkness overlay, blur, brightness, contrast, vignette
    ├── stickers_frames/         # Calligraphy & Decorative Elements
    │   ├── calligraphy_stamps.js# Vector calligraphy (Bismillah, Mashallah, Eid, Jummah)
```

## ⌨️ Keyboard Shortcuts

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> | **Undo** | Revert canvas to previous snapshot state |
| <kbd>Ctrl</kbd> + <kbd>Y</kbd> | **Redo** | Reapply undone action |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | **Delete Layer** | Delete currently selected canvas element |
| <kbd>Escape</kbd> | **Deselect** | Clear active selection or close open dialogs |
| <kbd>Arrow Keys</kbd> | **Nudge** | Move active layer by 1 pixel |
| <kbd>Shift</kbd> + <kbd>Arrow</kbd> | **Fast Nudge** | Move active layer by 10 pixels |

## 🚀 Getting Started

### Prerequisites
- Node.js (version 18+ recommended) or any modern web browser.

### Option 1: Run with Vite Dev Server (Recommended)
```bash
# Clone the repository
git clone https://github.com/umais-codes/urdu-photocraft.git

# Navigate into the project folder
cd urdu-photocraft

# Install dependencies
npm install

# Start development server
npm run dev
```
Open `http://localhost:5173` in your browser.

### Option 2: Zero-Build Direct Preview
Urdu PhotoCraft uses standard native ES Modules. You can open `index.html` directly in any modern browser or serve it via any static file server:
```bash
npx serve .
```

### Production Build
```bash
npm run build
```
The optimized bundle will be compiled to the `dist/` directory.
